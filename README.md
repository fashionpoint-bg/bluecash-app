# Fashion Point за Datecs BlueCash-50

Приложението Fashion Point за касов апарат Datecs BlueCash-50. С него касата във FashionPoint печата боновете и приема плащанията с карта на самия апарат.

Файлът за инсталиране е в [Releases](https://github.com/fashionpoint-bg/bluecash-app/releases/latest). Всяка версия е подписана от Datecs.

Апаратът започва работа, след като се закачи към обекта с код от Fashion Point.

Поддръжка: support@fashionpoint.bg
